# 普通实例与 Pro 的复用能力

核对日期：2026-11-26。依据 AutoDL 公开文档与公开控制台前端；未登录真实账号执行保存、克隆、创建或传输。公开前端说明当前网页行为，不构成稳定开放 API 契约。

## 能力矩阵

| 操作 | 普通实例 | 容器实例 Pro | GPUScout 当前入口 |
|---|---|---|---|
| 新建租用 | 选具体主机、单机卡数和镜像 | 指定卡型、候选地区等，由平台调度 | 库存手动租普通实例；Pro 使用独立模板 |
| 保存镜像 | 关机后保存系统盘，不含独立数据盘 | 关机后保存系统盘；没有独立数据盘 | 两者详情中分别提供保存，明确计费确认 |
| 本地区克隆 | 官方同地区迁移流程；系统盘必选，数据盘可选，后者在系统盘克隆后复制 | 控制台存在克隆；当前公开表单沿用源实例地区 | 软件接入普通实例同地区克隆；Pro 到专用控制台 |
| 跨地区直接克隆 | 普通克隆不能直接跨地区 | **尚未核实支持**，不能从自动调度推断 | 不提供未验证的 Pro 跨地区克隆按钮或调用 |
| 跨地区复用环境 | 官方推荐保存镜像，在新地区以「我的镜像」新建；数据盘独立传输 | 开放创建 API 可带镜像及候选地区，但这不是直接克隆能力或任意地区可用性的保证 | 普通实例提供迁移向导；Pro 需先在控制台确认具体能力 |
| 本地常用配置 | 普通租用方案，保存镜像来源、卡数、预算和可选硬件偏好 | 原有 Pro 模板，保存调度规格与开机配置 | 同一「租用方案」页分开管理，旧规则绑定和导入导出保留 |
| 凭证 | 网页登录凭证，控制台内部接口 | 开发者 Token，官方开放 API | 不把普通实例的请求或数据盘选项直接套给 Pro |

## 磁盘语义

普通实例的系统盘镜像不包含独立数据盘 `/root/autodl-tmp`。同地区克隆勾选数据盘后才会复制数据盘；跨地区传输走单独流程，需核对目标路径、容量和文件完整性。

Pro 只有系统盘，`/root/autodl-tmp` 是系统盘中的普通目录。公开文档说明 Pro 重置系统/更换镜像时默认保留该目录，这是特定操作的保留规则，不等于独立数据盘，也不表示释放实例后数据仍在。保存镜像、克隆和普通目录保留不能混为一谈。

保存镜像是云端快照动作，可能收取存储费用；保存租用方案只是本地偏好。提交保存请求不代表镜像就绪；新实例编号出现不代表磁盘复制或环境验收完成。源实例不会被软件自动释放。额外存储费用可能在关机后继续产生，具体以平台为准。

## 证据入口

- [普通实例跨地区迁移](https://www.autodl.com/docs/migrate_instance/)：系统盘保存镜像后，在新地区选择「我的镜像」创建；跨地区数据盘走公网单独传输。
- [同地区迁移](https://www.autodl.com/docs/migrate_instance_2/)：先关机，以系统盘克隆新实例，可选随后拷贝数据盘。
- [Pro 数据说明](https://www.autodl.com/docs/instance_pro_data/)：只有系统盘；`/root/autodl-tmp` 目录与重置保留规则。
- [Pro 开放 API](https://www.autodl.com/docs/instance_pro_api/)：公开创建、镜像保存和私有镜像列表；核对时未找到公开的克隆端点。
- [普通实例控制台](https://www.autodl.com/console/instance/list) / [Pro 控制台](https://www.autodl.com/console/instance/pro/list)：需要用户自行登录核对当前账号权限和可用操作。

公开页面加载的资源中，`index-9a480443.js` 的 Pro 克隆组件将目标 `data_center` 初始化为源实例 `additional_info.data_center`，没有目标地区选择控件；`instance-pro-17a628a0.js` 定义网页内部的 `/api/v1/order/instance/pro/clone/payg`。这只能证明当前公开表单没有跨区选择，不能证明后台永久不支持跨区，GPUScout 也没有调用该未验证接口。

普通实例请求形状参考 `index-9ac72e59.js`、`index-ba90943d.js`、`myImage-8db2af83.js` 等公开资源，并用本地假 HTTP 服务器验证字段。测试数据按公开字段形状构造，未使用真实账号响应；资源名会随网站版本变化。
